# Guo et al. 2025

## Findings
- 20 LLMs can state the RPS Nash equilibrium (1/3 each) but do not play it.
- Pre-training bias alone does not explain the deviation; a semantic-free variant reveals **positional bias** (o1 favours the first option, DeepSeek-V3 the middle, DeepSeek-R1 first and last).
- Not checked: sequential patterns across rounds, effect of temperature or prompting (abstract only).

## Why it matters for us
- Two copies of the same model will share the same skewed, possibly history-dependent action distribution → non-zero conditional MI with no collusion (H1).
- Design implications:
  - **Shuffle option order per agent per round** (and map back) as an ablation. If false positives drop, the shared prior is positional.
  - Alternative from the plan's open question: ask for a probability distribution and sample it in code. Removes the shared sampling bias but changes what we study; report both if time.
- Gives a citation for "LLMs don't randomize" instead of asserting it.
